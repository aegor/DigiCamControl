# Digma DiCam Contoller — Android

Самостоятельное приложение для камеры DiCam/iCatch. Телефон напрямую открывает
PTP/IP-сессию на порту 15740 и RTSP-поток на порту 554. Компьютер, Go-сервер,
веб-сервер, WebView и установка FFmpeg не требуются. Библиотека LibVLC входит в APK.

## Подключение

1. Включите Wi-Fi камеры и подключите к нему телефон через настройки Android.
2. Если Android предупредит об отсутствии интернета, оставьте подключение к этой сети.
3. Запустите приложение. Адрес камеры по умолчанию — `192.168.1.1`.
   Кнопка **Камера** позволяет изменить адрес; он сохраняется между запусками.
4. **Record** запускает запись на карту памяти камеры, **Stop** останавливает её.
   Индикатор **● REC** обновляется после подтверждения команды камерой.
   При подключении приложение читает фактический режим камеры.

На время использования закройте другие контроллеры камеры: прошивка может
поддерживать только одну PTP-сессию. IP телефона назначается сетью камеры;
фиксированный bind `192.168.1.10`, использовавшийся на компьютере, здесь не нужен.
Приложение выбирает Wi-Fi для обоих каналов даже при включённом мобильном интернете.

## Поведение

- Горизонтальный полноэкранный интерфейс, видео масштабируется с сохранением пропорций.
- Проверка связи отдельным ICMP-монитором раз в секунду (таймаут 900 мс), как в Go.
  С версии 0.2.1 ICMP выполняется внутри APK через Android `Network.bindSocket`,
  без запуска `/system/bin/ping`; сокет привязан к той же Wi-Fi-сети, что и PTP.
- Режим читается при открытии PTP-сессии; постоянных PTP-запросов состояния нет.
  Record/Stop сериализованы; таймаут PTP-операции — 3 секунды.
- При потере связи внизу появляется `lost connection to camera`.
- Автоматическое открытие новой PTP-сессии после возвращения камеры.
- RTSP восстанавливается независимо от PTP, в том числе при переключении записи.
- При сворачивании приложения сетевые подключения освобождаются. Запись на камере
  продолжается; после возвращения приложение читает её фактическое состояние.
- В этой версии доступны Record/Stop; кнопок Photo и Burst нет.

RTSP URL: `rtsp://192.168.1.1:554/MJPG?W=720&H=400&Q=50&BR=5000000`.
Несмотря на имя MJPG, проверенная камера передаёт H.264. Используется LibVLC 3.7.7 с TCP-транспортом и встроенными декодерами.
LibVLC выбран для совместимости с нестандартным RTSP-ответом этой прошивки;
он также поддерживает MJPEG. Библиотека динамически включается в APK (LGPL 2.1).
Исходники и инструкции сборки: https://code.videolan.org/videolan/libvlcjni

## Сборка

Откройте папку `android` в Android Studio и запустите модуль `app`, либо:

```bash
cd android
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Требуются SDK Platform 37.0, Build Tools 36.0.0 и JDK, совместимый с Gradle 9.4.1
(подходит встроенный JDK установленной Android Studio). Минимальная версия —
Android 8.0/API 26. Target API 36 сохраняет совместимость с горизонтальной
ориентацией на больших экранах Android 16. Первая сборка скачивает зависимости;
при работе приложения интернет не нужен.

APK: `app/build/outputs/apk/debug/Digma DiCam Contoller.apk` (тестовая debug-подпись).

Кеш зависимостей и дистрибутив Gradle хранятся вне проекта, в стандартном
`~/.gradle` (на Windows — `%USERPROFILE%\.gradle`). Не задавайте
`GRADLE_USER_HOME` внутри репозитория. Локальный кеш задач `.gradle/`
создаётся Gradle в проекте отдельно.

## Проверки

Unit-тесты проверяют пакеты PTP, полноценный обмен через TCP с тестовой камерой,
восстановление занятой сессии, команды Record/Stop, чтение состояния и IP-адреса.
Отдельный тест проверяет потерю ping, закрытие старых соединений и новую PTP-сессию
после возвращения связи, без постоянного опроса состояния по PTP.

На телефоне проверьте видео, Record/Stop и REC, отключение/включение камеры,
восстановление видео после записи, сворачивание и возвращение в приложение.
Физический телефон должен быть подключён к Wi-Fi камеры. Эмулятор может обращаться
к камере через сеть компьютера; это только способ тестирования, не зависимость APK.

## Диагностика подключения

При ошибке откройте **Камера → Диагностика** или нажмите нижнюю строку состояния.
Там указаны версия APK, Android, IP камеры, Wi-Fi-интерфейс и последняя ошибка
ICMP/PTP. Текст можно выделить и скопировать. Версия 0.2.1 сохраняет target SDK 36:
дополнительное разрешение ACCESS_LOCAL_NETWORK вручную не запрашивается.

Проверка ICMP из процесса APK на подключённом тестовом устройстве (без открытия
PTP-сессии и команд записи):

```bash
./gradlew assembleDebug assembleDebugAndroidTest
adb -s <serial> install -r "app/build/outputs/apk/debug/Digma DiCam Contoller.apk"
adb -s <serial> install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <serial> shell am instrument -w -e camera_ip 192.168.1.1 com.dicam.controller.test/com.dicam.controller.PingInstrumentation
```

Локальные архивы инструментов вынесены в `~/.cache/dicam/`. Сохранённый ключ
подписи находится в `~/.android/dicam/debug.keystore` (вне Git); текущая
конфигурация Gradle не подключает его явно. Каталог `.deps/` не требуется.
