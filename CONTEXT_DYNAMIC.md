## Что изменено

- Добавлено автоматическое открытие браузера после успешного HTTP-ответа UI,
  один раз, без ожидания камеры. `--no-browser` отключает открытие. Для wildcard
  host используется loopback. Ошибка открытия логируется, сервер продолжает работу.
  Windows: ShellExecuteW/COM, macOS: open, Linux: xdg-open; без shell-командной строки.
  Windows EXE в dist обновлён вместе с SHA256, состав папки по-прежнему четыре файла.
  macOS-бинарник не пересобран и ещё НЕ содержит автооткрытие браузера.
- Unix ping вынесен без изменения поведения в `go/ping_unix.go`.
- `go/ping_windows.go`: Windows `IcmpSendEcho2Ex`, IPv4 source bind,
  timeout не более 900 мс с учётом deadline; отмена выполняющегося синхронного
  запроса может занять до 900 мс. IPv6 отклоняется явно. Внешний ping не требуется.
- `go/scripts/windows.sh`: Git Bash + MinGW-w64, локальный Go в `.deps/toolchain`
  либо Go из PATH. Makefile выбирает `dicam.exe` на Windows.
- `build-ffmpeg.sh`: Windows amd64, тот же архив/SHA-256 и минимальная конфигурация
  без GPL/nonfree. Исходники распакованы заново в каталог конкретной платформы;
  Mac-кеши не используются и сохранены. Исходники FFmpeg не модифицировались.
- Для native GNU Make используются относительные пути в сгенерированных
  `Makefile`/`config.mak`; `make V=1 install` предотвращает слишком длинную команду
  с дублированием списка заголовков. Все 101 заголовок libavutil установлены.
- `.configured-v2` сохраняет успешную конфигурацию для продолжения прерванной
  компиляции. При смене рецепта/компилятора нужно инвалидировать build/prefix
  или увеличить версию каталога/маркеров; иначе используются прежние настройки.
- Нативная `pkg-config-static-windows.c` добавляет `--static` и группу GNU ld
  `--start-group/--end-group` для взаимных ссылок между архивами FFmpeg.
  Это необходимо с u-config, который выдаёт avutil раньше swscale.
- `check-linkage.sh` проверяет PE imports по списку системных DLL, отклоняя
  динамический FFmpeg и сторонние runtime DLL.
- README содержит команды и ограничения. USB по-прежнему только Linux/V4L2.

- `make build`: успех; `objdump -f` подтверждает PE x86-64.
- `go test -race ./...`: все 29 тестов прошли, итог `ok dicam/controller 12.558s`.
  Использованы настоящие библиотеки FFmpeg, MJPEG/MP4, локальные TCP-имитаторы,
  PTP, восстановление и Windows ICMP loopback с bind/без bind.
  Автооткрытие проверено подставным обработчиком: готовность UI, однократный
  запуск, ошибка браузера, отмена ожидания, URL IPv4/IPv6/wildcard и флаг отключения.
  Реальный браузер в автоматических тестах не открывался.
- `go vet ./...`: успех.
- `node go/web/ui_test.cjs`: успех (Record/Stop, ошибки, recovery, server restart).
- `smoke-windows.py`: `--help` и запуск с `--no-browser` при пустом PATH, HTTP API и встроенный UI,
  Ctrl+C и штатный выход с кодом 0. Камера задана как `127.0.0.1`, использовалась
  отдельная скрытая консоль. Процесс остановлен, реальная камера не затрагивалась.
- PE imports: только `bcrypt.dll`, `IPHLPAPI.DLL`, `KERNEL32.dll`, `msvcrt.dll`,
  `ole32.dll`, `SHELL32.dll`, `WS2_32.dll`; FFmpeg/GCC runtime DLL отсутствуют.

- macOS/Linux после изменений здесь не пересобирались; Windows USB не добавлялся.

инструкции пересборки указывают на этот файл. В tar сохранены executable-биты для
macOS-бинарника, shell-скриптов и gradlew. Кеши, локальные пути SDK, ключи и `._*`
в пакеты не включаются. Старые `._*` в рабочем дереве оставлены без изменений.
`SHA256SUMS` содержит восемь записей стандартного вида `<hex>  <filename>`.

входные суммы, архитектуры PE/Mach-O и наличие лицензий в APK, не подключается
к сети/камере, не меняет Git. Имеющиеся бинарники не пересобираются.
Исходники — снимок на момент упаковки; Mac-бинарник собран Go 1.24.5 до Windows-
адаптации, поэтому побайтовая воспроизводимость перенесённого файла не заявляется.
Проверка пакетов выполнена: все восемь SHA-256 совпадают, бинарники внутри архивов
совпадают с отдельными файлами, отдельный FFmpeg имеет зафиксированную сумму.

присутствует. ZIP проверен по CRC, macOS executable имеет mode 0755. Извлечённый
Windows exe успешно выполнил `--help` с пустым PATH. Повторная упаковка дала
побайтово идентичные архивы и SHA256SUMS.

v0.2.1 — имя каталога из Android, не подтверждённый Git-тег и не встроенная версия
