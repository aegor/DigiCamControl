## Последняя схема сборки

- `.cache/<target>/`: npm, Electron, electron-builder, Go build/modules, native FFmpeg, bin.
- `electron/resources/<target>/`: проверенный движок, manifest, лицензии/исходники.
- `electron/release/<target>/`: приложения, установщики и служебные файлы.
- `dist/`: установщики и отдельные SHA-256; полностью исключён из Git.
- На macOS target `darwin-arm64`, на Windows x64 — `win32-x64`.
  Каждая ОС использует отдельную рабочую копию. `node_modules` не переносить.
- После clone: `cd electron`, `node scripts/build.cjs install`, `npm run backend`.
  Затем `npm test`, `npm run test:go`, `npm run vet:go`, `npm run test:smoke`,
  `npm run pack` / `npm run dist`. `npm run paths` выводит расположение кешей.
- Windows: Git Bash из Git for Windows, не WSL; пути переопределяются через
  `DICAM_GIT_BASH` и `DICAM_MINGW_BIN`. Подробности — `electron/README.md`.
- Go/FFmpeg и Node-зависимости пересобраны в новых каталогах. Проверены 12 Node-тестов,
  Go `-race`, `vet`, smoke настоящего окна с loopback-камерой. Подтверждено изменение
  FFmpeg-prefix при смене CFLAGS и стабильность prefix при одинаковых входах.
- Проверены macOS .app, подпись и полный выпуск DMG новой командой `dist`.
  В смонтированном DMG проверены правильный Info.plist, подпись и совпадение Go-бинарника
  с результатом упаковки. SHA-256 установщика совпал с созданным `.sha256`.
- Windows Electron NSIS-сборка выполнена 2026-10-26 в текущей Windows-копии.
