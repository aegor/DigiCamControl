## Это глубокий форк экспериментального проекта https://github.com/dropchop/actionCamController

> Оригинальный readme этого проекта доступен в [README-orig](README-orig.md)

### Что нового? Практически всё.

1. тотально переделан layout проекта на python/flask. теперь видео открывается на полный экран с масштабтрованием, убрана кнопка "сделать фото", добавлены полоски диагностики соединения, усовершенствован весь UI.
2. организован механизм reconnect с перезагрузкой видео при удачном соединении, в противном случае в строке статуса отображается сообщение о попытке соединения
3. Добавлены приложения на go (нативные бинарники) для Mac OS и Windows
4. Добавлено приложение для Android, которое работает крайне стабильно, при наличии установления WiFi-соединения с камерой, в отличие от "фирменных" приложений от iSmart (iSmartDV 2) и прочих других.

> Собранные бинарники лежат в [Releases](https://github.com/aegor/DigiCamControl/releases)

> Запуск програм с ключём --help покажет остальные ключи запуска
