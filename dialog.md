# Журнал работы над проектом

## 2026-10-25 — Windows Go, локальный релиз и правильный корень проекта

Запись содержит итоги диалога, а не дословную стенограмму.

1. По CONTEXT-файлам продолжена Windows-сборка Go-контроллера: FFmpeg 8.0.3
   встроен статически, добавлен Windows ICMP с IPv4 bind, настроены Git Bash,
   MinGW-w64 и pkg-config. Готовому EXE не нужны Go, Python или внешний FFmpeg.
2. Подготовлен локальный релиз v0.2.1. Первоначальный запрос о публикации
   пользователь уточнил: только локально, без GitHub Release.
3. После обсуждения статической линковки пользователь попросил убрать вложенный
   архив исходников FFmpeg из desktop-пакетов. Затем окончательно потребовал
   оставить в dist/v0.2.1 только Windows EXE, macOS ARM64, Android debug APK
   и SHA256SUMS. Все остальные файлы удалены; расширенные пакеты не восстанавливать.
4. Добавлено автоматическое открытие браузера после готовности HTTP UI, без
   ожидания камеры. Флаг --no-browser отключает его. Ошибка открытия не завершает
   сервер. Windows EXE и SHA обновлены; macOS-бинарник пока без этой функции.
5. До переноса прошли 29 Go-тестов с -race, vet, проверка PE imports, запуск
   при пустом PATH и штатное завершение по Ctrl+C. Ранее прошли UI-тесты.
   Автооткрытие тестировалось подставным обработчиком, реальное окно браузера
   в автотестах не открывалось. Физическая камера Windows не проверена.
6. Правки .gitignore сначала ошибочно выполнялись в соседней копии проекта.
   Пользователь указал единственный правильный корень:
   F:/Hardware/DICAM/DigiCamControl, и запретил его покидать.
   Все дальнейшие действия выполняются только здесь и в его подкаталогах.
7. В правильной папке .gitignore отсутствовал на диске, но сохранился в индексе.
   Он восстановлен с общими правилами **/__pycache__/, **/dist/, *.egg,
   *.egg-info/, .eggs/ и ._*. Из индекса исключены 143 служебные записи;
   локальные файлы не удалялись. Проверка Git подтвердила исключения.
8. При сохранении памяти обнаружен уже существующий HEAD 2ab4025 (android Go),
   ветка main. Перед обновлением документов рабочее дерево чистое, игнорируемых
   записей в индексе нет. Новые коммиты и теги в этом шаге не создавались.
9. Все три SHA256 в новой папке перепроверены и совпали. Папка релиза содержит
   ровно четыре файла. Для дальнейшей сборки нужно заново подготовить FFmpeg
   внутри нового корня: pkg-config metadata пока указывает на прежнюю папку.
10. Android хранится как gitlink без .gitmodules. Это зафиксировано как вопрос
    для будущего переноса/публикации; структура не изменялась.

По запросу пользователя обновлены CONTEXT_STATIC.md и CONTEXT_DYNAMIC.md.
Файл dialog.md ранее отсутствовал, поэтому создан с этой записью.
Следующие действия: подготовка зависимостей в новом корне при запросе на сборку;
реальный тест камеры только совместно с пользователем. Не возобновлять
бесконечные реконнекты, не менять VPN и не запускать другие контроллеры камеры.
