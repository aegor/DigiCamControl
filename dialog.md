```powershell
Remove-Item Env:NODE_OPTIONS -ErrorAction SilentlyContinue
if (Test-Path Env:NODE_OPTIONS) { throw 'NODE_OPTIONS is still set' }
node scripts/build.cjs test:smoke
```

Результат: Electron smoke passed, код выхода 0. Проверены loopback-камера
127.0.0.1, отклонение недопустимой команды, отсутствие require в renderer,

«Неизвестная команда» ожидаемо: это часть проверки отклонения команды.
Сброс NODE_OPTIONS относится только к окружению запуска; глобальные переменные
Windows не менялись. Физическая камера в этом тесте не использовалась.
По следующей просьбе пользователя результат дописан в этот журнал.
